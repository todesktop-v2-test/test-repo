# ToDesktop v2 test repo

The v2 spike's fixture daemon (`acme-agent`, with the ToDesktop updater),
built on GitHub Actions and uploaded to the dev edge
(`v2-edge-dev.todesktop.workers.dev`) as the app `acme-agent-dev`. Run the
Release workflow, or push a `v*` tag.

The crates and the bundled upload action are copied from the ToDesktop
monorepo's `v2/` directory.
